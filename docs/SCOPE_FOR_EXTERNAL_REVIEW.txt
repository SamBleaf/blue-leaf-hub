PHASE 0 — fastest value (the two reported bugs + two client-facing emails)
--------------------------------------------------------------------------------
[DONE]    B0  Invite link broken for new users (e.g. a director couldn't load it)
              Cause: invite URLs were built from APP_URL with a localhost
              fallback; 4 different domains hard-coded across the code.
              Fix: one shared appBaseUrl() helper -> https://blueleafhub.com.au.
[BLOCKED] B0  Owner to: confirm APP_URL is set in Railway prod; run the zero-code
              probe (generate a fresh invite, read the emitted URL); resolve the
              deploy-topology question (single-origin Railway vs Vercel+Railway)
              before deleting the dead vercel.json; re-invite the affected user.
[DONE]    W1  Worker-view task bug: a carpentry task added to a job didn't show
              in the worker app. Cause: the worker task list was inferred from
              the worker's latest timesheet. Fix: explicit, persisted job picker
              in the Worker PWA; inference removed; service-role endpoints now
              validate every client param (uuid + category whitelist + job scope).
[DONE]    BQ-13 Progress-claim email: replaced plain-text <pre> with a branded
              HTML template (+ optional bank/payment block).
[DONE]    BQ-14 Variation email: same upgrade.
[BLOCKED] BQ-13/14 bank block needs migration 106 (company_profile bank columns)
              applied + the real BSB/account number backfilled by the owner.

PHASE 1 — foundational fixes + first cross-module pieces
--------------------------------------------------------------------------------
[DONE]    DATE Cross-cutting AU-local date fix: weekStart()/"today" used UTC, which
              is the previous day during AEST mornings — corrupts week boundaries
              and (downstream) payroll. New noon-anchored helpers + regression test.
[DONE]    CARP Carpentry tasks made first-class: the create endpoint + UI now set
              category + assignee (previously every task was general/unassigned),
              so the worker job-picker's category filter is meaningful.
[BLOCKED] CARP Migration 107 (site_tasks "exactly one of project/carpentry job"
              constraint, added NOT VALID) to be applied; run the documented
              pre-apply audit + VALIDATE after.
[DONE]    FAB  Quick-add "+" relabelled "Task" -> "Site Task", gated to schedule
              editors, deep-links to the Operations Site-Tasks panel (auto-opens).
[DONE]    DOCS Document Templates workstream (BQ-12..51) added to MASTER_PLAN.md.
[DONE]    FIN  Finance invoice viewer: "View PDF" while approving/matching, in
              both the Approval queue and the Inbox; IDOR-safe stream endpoint;
              email-ingested invoices now persist their file at ingest (was the
              gap that left the viewer empty for them); PDF/image/HEIC handling.
