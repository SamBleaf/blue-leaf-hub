# SOP Audit — 2026-06-16

> Method: six parallel audit agents compared the live app (pages in `src/pages/`, routes in `server/lib/`) against the 116 SOPs in `docs/sops/` and `SOP_INDEX.md`.
> Status: **findings only — no SOPs have been written or changed yet.** Awaiting decisions (see Section 5) before remediation.

---

## 1. Headline

The SOP set is structurally healthy — every existing SOP has a Section 14, and only one broken-link cluster was found. The problem is **coverage drift**: the app has grown ~40 user-facing workflows and one entire architectural pillar (the Knowledge Core / Confirm Queue) that the SOPs never anticipated, plus ~18 SOPs whose steps no longer match the screens.

| Category | Count |
|---|---|
| Missing SOPs (workflow exists, no doc) | ~42 |
| Outdated SOPs (steps no longer match app) | ~18 |
| Whole undocumented module (Knowledge Core) | 1 (needs new folder `20_`) |
| Broken internal links | 3 (one file) |
| Template/Section-14 conformance issues | modules 02 & 04 + a few short test scripts |
| Index inconsistencies | total count, 1 mislabel, 1 status drift |

## 5. Decisions needed before remediation

1. **RFQ Engine vs RFQ Packages.** Both features are live (`/rfq-engine` wizard writing to `rfqs`; `/rfq-packages` writing to `rfq_packages`). The 04-xx SOPs document Packages but call it "the Engine," and leads hand off to the wizard. Which is the canonical/supported path going forward? This determines whether we rewrite 04-xx or add a new wizard SOP set.
2. **Project selector (01-02).** The documented top-bar selector was never built (project context comes from the Operations route). Rewrite the SOP to match reality, or retire it?
3. **Where do Supervisor-mode SOPs live?** New folder, or under `05_operations/` / `07_site_diary/`?
4. **Undocumented Settings integrations** (Meta, Resend, GSC/GA4/GBP, cost model, signature, notifications) — house under folder `12`, or in their module folders (18/19/09)?

## 6. Suggested remediation order

1. **Knowledge Core (`20_`)** — highest risk; an entire pillar with money/compliance consequences is undocumented.
2. **Workforce (10-02 → 10-09) + Worker PWA** — large staff-facing surface with only one (partly wrong) SOP.
3. **WHS Setup engine (08-07 → 08-09)** — safety/compliance.
4. **RFQ Engine wizard (04-10)** — pending Decision 1.
5. Fix the broken links + outdated 00/01/10 SOPs (quick wins, high staff-facing impact).
6. Rewrite 14-02; backfill the remaining missing SOPs by priority.
7. Reconcile SOP_INDEX totals, the 09-07 rename, and the 18-01 status.

*Each new SOP must follow the full template and include a complete Section 14 (TC-01–TC-05 + ≥1 feature-specific case), and be added to SOP_INDEX.md (`test_status: untested`) and SOP_CHANGELOG.md, per the SOP Law in CLAUDE.md.*
