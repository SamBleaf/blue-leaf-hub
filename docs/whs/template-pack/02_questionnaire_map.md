# Operations-Start Questionnaire Map

## Goal

The questionnaire captures missing site-specific WHS information once, then the risk engine generates the correct documents, SWMS, permits, inspections, registers, toolbox talks and site board warnings.

## Module 0: Construction Method Assessment

Auto-derived from existing job data and confirmed only.

Questions / fields:

- Project type: new home, addition, renovation
- Storeys: single, double, triple
- Frame type: timber, steel, mixed
- Roof type: trusses, conventional, flat roof, pitched roof
- Retaining walls: yes/no
- Basement: yes/no
- Suspended slab: yes/no
- Structural steel: yes/no
- Demolition scope: yes/no
- Masonry/concrete cutting: yes/no
- Steep site: yes/no
- BAL / bushfire zone: yes/no
- Pre-1990 renovation: yes/no

Outputs:

- Pre-selects high risk work in Module 5
- Triggers asbestos prompt for older renovation work
- Triggers fall, structural, excavation, plant and silica assessments where applicable

- Emergency vehicle access?

## Module 4: Site Hazards

Questions:

- Overhead powerlines?
- Underground services?
- Adjacent road?
- Public pedestrian access?
- School/shop/public interface nearby?
- Neighbouring properties impacted?
- Existing structures?
- Retaining walls?
- Steep terrain?
- Bushfire risk?
- Flood risk?
- Tree hazards?
- Restricted access?

Outputs:

- Site Safety Plan
- Site Board warnings

## Module 5: High Risk Construction Work Gate

Confirm yes/no:

- Work at heights over 2m
- Roof work
- Scaffold
- Excavation or trenching
- Demolition
- Structural alteration or temporary support
- Crane lifts
- Telehandler
- Mobile plant
- Hot works
- Silica-generating work
- Hazardous chemicals
- Confined spaces
- Asbestos risk
- Energised electrical work
- Suspended slab/formwork

Outputs:

- Applicable SWMS
- Permits
- Inspections
- Registers
- Toolbox talks
- Training requirements

## Module 6: Excavation Assessment

Visible only if excavation/trenching selected.

Questions:

- Maximum depth?
- Excavation near services?
- DBYD completed?
- Services located and marked?
- Excavation near existing structure?
- Benching/shoring required?
- Spoil storage location?
- Plant operating near excavation?
- Rain/collapse risk?
- Exclusion zone required?

Outputs:

- Excavation SWMS
- Excavation Permit if required
- Excavation inspection schedule
- Underground services checklist
- Excavation toolbox talk

## Module 7: Falls and Height Assessment

Visible only if heights, roof or scaffold selected.

Questions:

- Maximum working height?
- Roof pitch?
- Scaffold required?
- Edge protection required?
- Void protection required?
- EWP required?
- Ladder use expected?
- Anchor points/harness system?
- Rescue plan required?
- High wind exposure?

Outputs:

- Working at Heights SWMS
- Roof Work SWMS
- Scaffold SWMS/Register
- Rescue Plan
- Height controls checklist
- Falls toolbox talk

- Chasing?
- Core drilling?
