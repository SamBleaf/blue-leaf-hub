# Blue Leaf Building WHS Template Pack

> Blue Leaf Building WHS Template Pack
> Template status: Draft for WHS/legal review before live use
> Generation method: Fixed template + structured merge fields + risk rules
> Do not use AI-generated legal text in live documents without review


## Purpose

This pack contains the first complete WHS content set for Blue Leaf Hub.

It is designed to be used by Claude Code as source material for:

- WHS document templates
- merge fields
- questionnaire-driven document generation
- SWMS generation
- permits
- registers
- legal/usability review notes

## Core principle

Do not build a document system. Build a data system that outputs documents.

Every document in this pack is designed to be populated from:

1. Existing project/job data
2. WHS operations-start questionnaire
3. Risk engine outputs
4. Approved fixed template content

## Legal note

This pack is a working template set, not legal advice. Before live use, Blue Leaf Building should have the templates reviewed by a competent WHS consultant or lawyer familiar with South Australian residential construction.
