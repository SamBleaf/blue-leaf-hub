## 8. Control measures

The following controls must be applied where relevant:

- plan the work before starting
- inspect work area before use
- isolate the public and other trades from the work area
- use the safest available access method
- maintain exclusion zones
- use competent workers
- inspect plant, tools and equipment
- use required PPE
- keep the work area clean
- stop work if conditions change
- report hazards and incidents immediately

{{task_specific_controls}}

## 9. Monitoring and review

Controls must be monitored by:

- supervisor checks
- worker feedback
- toolbox talks
- inspections where required
- permit checks where required

Review this SWMS if:

- the task changes
- site conditions change
- new hazards are identified
- an incident or near miss occurs
- controls are not being followed
- the SWMS is found to be ineffective
