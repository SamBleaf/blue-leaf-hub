## Review procedure and release gate

For each active numerical installation row, save document title/edition, PDF page and printed page if different, table/row, all column headers, footnotes and applicable alternatives. Compare a transcription against the readable full table. Text extraction can flatten columns; never reconstruct ambiguous pairings from snippets. This research does not claim visual verification of every table.

The candidate assemblies in the JSON deliberately contain no automatically active fixing rows. Capture project-specific reviewed details as an alternative, with provenance. Manufacturer dimensions may be usable while an assembly's support rules remain unresolved. Complete AAC guide review is outstanding. Do not infer AAC spacing, screw counts, adhesive yields or control-joint limits from another brand.

This pack links manuals rather than redistributing them. Manufacturer installation summaries are concise; implementation algorithms are original proposed software behaviour. Similar-app comparisons concern documented capabilities, not independently tested performance.
