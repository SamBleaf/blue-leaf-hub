21 | MASTER REGISTER QUESTION LIBRARY — ACTUAL EMPLOYEE CONTENT
BLUE LEAF RESIDENTIAL WORKFLOW v1.0 | 07 NOVEMBER 2026
AUTHOR: ChatGPT product/content specification informed by ZJ/Routleys/TLI/Rylock reference material and public NATSPEC, Metricon, Buildertrend and ConstructionOnline documentation. NOT an extract of paid NATSPEC clauses or copyrighted competitor copy.
STATUS: PROPOSED CONTENT FOR IMPLEMENTATION; NOT A CLAIM THAT QUESTIONS ARE ALREADY STORED IN HUB.

PURPOSE
A staff-operated conversation guide for site and floor plan walkthroughs, not a 150-field mandatory survey. The full library ensures coverage across projects; each room presents only 4–8 relevant topic groups and 1–3 questions at a time. Answers can be a short selection, a note or not applicable. Office users expand details progressively; multiple audiences get the right document extracts. A standard design/selection can apply to whole house, with per-room exceptions.

LEGEND
P = prompt identifier; W = whole-project; R = room; E = building element; X = renovation overlay; M = management/procurement overlay.
[C] Concept Meeting/Presentation: broad purpose and inclusion. [D] Detailed after PTSA, or staff work-ahead. [T] Tender/contract verification, not extra client question.
CORE = most residential projects; NEW = new dwelling; RENO = renovation / extension; OPT = only when scoped; ROOMTYPE = specific room.
KIND: FACT = read existing Sales/Hub field and DO NOT reask if present; SCOPE = included work/ownership; REQUIREMENT = desired outcome/performance; SELECTION = product/finish; TECH = design/consultant verification; ACTION = question/owner.
Each library line is a question family, not necessarily an individual DB field. If a related Sales field already exists, show as 'Already on file' rather than asking it again.

HOW THE WORKSHOP FEELS
Open current plans → Project and Whole House → follow levels/rooms in drawing order → current room scope → key finishes/fixtures/architectural details → what's missing → Save & Next. If a room remains untouched, that's OK. 'Not yet discussed' is distinct from 'not applicable' or 'excluded'. At the end show the decisions that actually affect the next project milestone.
Ask the client only what they can reasonably know. Questions about engineering, compliance or installation remain internal designer/consultant actions, not an expectation that a homeowner chooses technical details.

1 | ENTRY: PROJECT CONTEXT (MOSTLY PREFILLED FROM SALES)
P-001 [FACT/C] Project identity and address. Prompt to staff only if missing: Are we working on the correct client and site? Show current Sales value.
P-002 [FACT/C] Drawings. Which plan set, sheet list, issue date and revision are we reviewing? Link existing document record; no reupload if present.
P-003 [FACT/C] Concept Meeting/Presentation record and key decisions already made. Surface existing meeting facts; never force re-entry.
P-004 [FACT/C] Client budget target, timing expectations and design priorities. Show current dated Sales fact; ask only to confirm material changes.
P-005 [REQUIREMENT/C] What do you most want to improve: space, natural light, comfort, privacy, entertaining, storage, accessibility, low maintenance, energy use? Pick up to 3 priorities plus note.
P-006 [SCOPE/C] What parts of the property are in this project, what are possible extras, and what is explicitly future work? Tag areas as Included / Optional / Excluded / Deferred.
P-007 [SCOPE/C] Physical project type: New Build / Renovation / Extension / Combined. Delivery model separately Design & Build / Build Only / Management / Other; never combine types in one ambiguous field.
P-008 [SCOPE/C] Will the property remain occupied or operational through work? Record temporary facility and access requirements only when relevant.
P-009 [ACTION/C] Which decisions must be made before the next architect issue, budget check or PTSA? Owner, not necessarily due date.
P-010 [FACT/C] Existing architects/consultants/suppliers and known agreements; link from Hub, not new text if authoritative contact already exists.

2 | WHOLE-PROJECT SITE / EXISTING CONDITIONS
W-001 [SCOPE/C CORE] Site access: restricted driveway, narrow site, crane/delivery access, neighbour restrictions, steep slope or parking? Note known facts, inspection tasks.
W-002 [TECH/D CORE] Survey, boundaries, easements, services, geotech and site levels: which reports exist and which are required? Internal consultant action, not client specification.
W-003 [SCOPE/C OPT] Trees, retaining walls, external structures and landscaping affected by construction? Include/retain/protect/remove/by others.
W-004 [SCOPE/C RENO] What is being demolished, retained, altered and made good in the existing building? Record by area, not one vague demolition line.
W-005 [TECH/D RENO] Existing structural, moisture, termite, asbestos/contamination, roof and foundation conditions: inspected / assumed / needs test; source.
W-006 [SCOPE/C RENO] What existing finishes and fixtures must be protected and/or matched? Note acceptable variation or inability to match exact old products.
W-007 [SCOPE/C RENO] Will the family live on site? Work zones, temporary kitchen/bathroom, dust separation, service outages and safe access.
W-008 [TECH/D RENO] Where do new and existing work connect: roof, wall, floor, drainage, electrical, thermal envelope? Add interface action and drawing ref.
W-009 [REQUIREMENT/C CORE] Overall project quality priorities: standard / upgraded / individually specified, and where is investment most important? Do not fabricate a universal inclusions package.
W-010 [SCOPE/C CORE] External works scope: driveway, landscaping, paths, fencing, retaining, pergola, pool or boundary work included/excluded/deferred?
W-011 [ACTION/C CORE] Unknown conditions likely to affect cost and design. Is investigation, contingency, exclusion or alternate scope appropriate?
W-012 [TECH/D CORE] Planning/building approval and consultant design responsibilities. Identify who verifies requirements, not legal assertions based on questionnaire.

W-014 [SELECTION/C CORE] Roof and gutter colour/material preference; roof profile/pitch/box gutter details to architect later.
W-015 [REQUIREMENT/C CORE] Windows and glazing priorities: frame appearance, opening use, sun/shading, privacy, thermal/acoustic performance, insect screens.
W-016 [REQUIREMENT/C CORE] Envelope quality: comfort/energy efficiency, insulation, airtightness and moisture management priority. Technical compliance by designers.
W-017 [SELECTION/C CORE] General interior floor palette by zone: timber/laminate/hybrid/tile/carpet/polished concrete, wet-area separate.
W-018 [SELECTION/C CORE] Internal doors and trims: standard or feature doors, general door heights, skirting/architraves/cornice and hardware style.
W-019 [SELECTION/C CORE] General paint and ceiling finish direction: warm/cool palette, matte/sheen, square set/cornice, feature areas.
W-020 [REQUIREMENT/C CORE] Heating/cooling, ventilation and hot water preference; any required comfort zones or special rooms?
W-021 [REQUIREMENT/C CORE] Electrical, smart home, data, solar/battery/EV charging ambitions; note special requirements, not layouts yet.
W-022 [SCOPE/C CORE] Window furnishings, appliances, loose furniture, fireplaces, landscaping, security and automation: included, by client, excluded or future?
W-023 [SCOPE/D CORE] Standard supply/installation responsibilities for selected products and any client-supplied items; warranty and lead time implications noted internally.
W-024 [TECH/D CORE] Document current building performance goal and required consultant checks (energy, thermal, fire, acoustic, moisture, accessibility as applicable). No automatic certification label.

M-001 [SCOPE/C] Who owns design coordination: client architect, Blue Leaf, other? Design deliverables and communication route.

M-006 [SCOPE/C] Programme and interface responsibility between other trades and Blue Leaf; site access/occupation risks.

14 | SHORT CONCEPT MEETING PATH — DO NOT SHOW THE WHOLE LIBRARY
A 10–20 minute concept or plan walkthrough should ask just:
1. Confirm drawing revision and project goals already on file.
2. Which areas are in scope / retained / excluded?
3. What material/quality direction applies across the home?
4. Walk rooms: what's changing, primary finish, joinery/fixture needs, services, unresolved issues.
5. What are the 3–5 biggest choices that affect budget or design?
6. Which consultant action or client decision comes next?
Clients should not be asked to pick waterproofing systems, slab reinforcement or compliance ratings in this workshop.

15 | ACCEPTANCE CRITERIA FOR CONTENT IMPLEMENTATION
- Question metadata can select by room type, physical project type and stage without thousands of condition branches.
- Whole-house standard prompts appear once, room exceptions only when needed.
- No duplicate prompts for budget/client/address or contact details already in Sales.
- New builds do not show renovation retained/make-good questions except activated scope.
- Bathrooms show plumbing/wet-area specifics; living rooms do not.
- Construction management overlays ownership and procurement questions without changing physical project type.
- Scope-only items never generate selection-approval tasks in portal.
- Unknown/not discussed ≠ N/A ≠ excluded ≠ existing retained ≠ decision pending.
- Outputs include relevant included/excluded items, status, assumptions and source drawing revision; clients don't see internal engineering/costing administration.
- Normal PTSA signed milestone increases detail, but staff can choose to work ahead. No payment gate.
- Custom fields are possible but stable IDs/category mapping maintained; staff cannot overwrite approved information without recorded review.
